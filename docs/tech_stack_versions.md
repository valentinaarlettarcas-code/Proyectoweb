# Reporte de Versiones: Django y Django REST Framework (DRF)

Para el desarrollo del Servicio de Comercio (Backend), se han verificado las fuentes oficiales para garantizar compatibilidad, seguridad y soporte a largo plazo.

### Versiones Recomendadas
*   **Python:** 3.10+ (Requerido para las versiones modernas de Django).
*   **Django:** 5.2 LTS (Long Term Support). Es la versión con soporte extendido más reciente.
*   **Django REST Framework (DRF):** 3.15+. Totalmente compatible con Django 5.x.

### Fuentes Oficiales Consultadas
1.  **Django Supported Versions:** https://www.djangoproject.com/download/
2.  **DRF Requirements:** https://www.django-rest-framework.org/#requirements
